# R'lyeh Protocol

크툴루 신화를 기반으로 한 1인용 보스레이드 카드게임 프로토타입입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소로 접속하면 됩니다.

## 현재 구현된 기능

- 플레이어 덱 / 손패 / 버린 카드 더미
- 보스 패턴 덱
- 체력, 동기화율, 오염도, 인류 잔존율
- 현현도, 현현체 내구, 의식 진행도
- 오염도 기반 폭주 카드 시스템
- 튜토리얼 보스: 심해인 대주교
- 승리 조건: 의식 진행도 100
- 패배 조건: 체력 0, 동기화율 0, 현현도 100, 인류 잔존율 0
